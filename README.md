# Sales and Customer Funnel Analysis using Power BI

## Overview
This project analyzes e-commerce sales data using Power BI to understand transaction performance, customer behavior, and long-term customer value.

The dashboard transforms raw data into interactive visual insights, helping identify trends, evaluate key performance indicators, and support data-driven business decisions.

---

## Objectives
- Analyze overall sales performance and revenue trends  
- Understand customer purchasing behavior  
- Evaluate key business metrics such as revenue, average order value, and retention  
- Identify high-performing regions and products  
- Build an interactive dashboard for business insights  

---

## Tools and Technologies
- Power BI Desktop  
- DAX (Data Analysis Expressions)  
- Power Query  
- Excel  

---

## Dashboard Features
- KPI tracking for sales, quantity, and customer metrics  
- Dynamic filtering for interactive analysis  
- Region-wise and city-wise performance insights  
- Time-based trend analysis  
- Customer segmentation and repeat purchase analysis  

---

## Key Analysis Performed
- Sales trend analysis over time  
- Customer segmentation (repeat vs single customers)  
- Regional performance comparison  
- Payment method analysis  
- Product category performance evaluation
